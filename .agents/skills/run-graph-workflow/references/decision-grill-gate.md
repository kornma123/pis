# 决策澄清关卡

仅在 `REQ-v1` 冻结前存在关键决策歧义，或用户明确要求 grill 方案时读取。目标是锁定会影响下游的产品与设计决定，不是增加形式化访谈。

## 选择模式

| 模式 | 使用条件 | 主要产出 |
|---|---|---|
| `skipped` | 需求已清楚；事实可查明；任务低风险、可逆或走快速路径 | 跳过理由 |
| `grill-lite` | 有少量关键取舍，但不需要长期维护的领域文档 | 锁定决策、假设、未决分支 |
| `grill-with-docs` | 涉及领域术语、边界、数据所有权、难逆架构取舍，且多个下游节点需要稳定依据 | 锁定决策、术语表、必要的 ADR 候选或 ADR |

不要默认先完整运行 `grill-lite`，再完整运行 `grill-with-docs`。文档模式是在同一轮追问中增加受控的文档产出。

以下情况不启用：答案能从代码、文档或现场状态查明；只是实现细节；任务明确且容易回滚；协调成本高于错误风险。用户显式调用整个 Graph Skill 但任务明显过小时，说明原因并走快速路径。

## 执行顺序

1. 先查证：读取获准范围内的代码、文档和现场事实，消除可调查问题。
2. 建立决策树：仅列出会影响范围、接口、数据、权限、架构、验收或风险的分支及依赖。
3. 深度优先追问：优先解决阻塞最多下游的上游决定；每轮只问一个问题并等待反馈。
4. 给出建议：每个问题都附主 Agent 的推荐答案、简短理由和主要代价，不把选择负担完全推给用户。
5. 记录结果：把回答归类为已锁定、显式假设、非关键延后或仍阻塞；发现矛盾时立即指出。
6. 判定停止：输出关卡合同；只有关键分支清楚后才允许冻结 `REQ-v1`。

## 问题与成本预算

- `grill-lite` 默认最多 5 问；高风险且每问仍产生新信息时最多 8 问。
- `grill-with-docs` 默认最多 12 问，绝对上限为 15 问。
- 每次只推进一个问题；不要在一条消息中堆叠问题清单。
- 所有关键分支已有答案，或最近 3 个回答没有产生新分支时提前停止。
- 用户疲劳、决定低成本且可逆，或继续追问的预期收益低于协调成本时停止；把非关键项显式延后。
- 到达上限仍有关键歧义时返回 `blocked`，交给人决定；不得自动扩大问题预算。

用户主动说“够了”不自动等于通过：若仍有关键分支，简短说明风险并让用户选择锁定一个答案、明确延后，或停止任务。

## 文档模式

术语表只记录项目领域特有的规范术语、简短定义和需要避免的同义词，不写实现细节。仅当决定同时满足以下三项时才形成 ADR：

1. 难以逆转，改变成本明显；
2. 缺少背景时会让未来接手者困惑；
3. 存在真实备选方案并作出了有依据的取舍。

先声明允许写入的文档路径和唯一写入 owner。决定尚未锁定、项目未授权写入或跨设备目标没有共同文件位置时，只返回可复制的术语表或 ADR 候选，不修改项目。文档写入不等于实现获准，也不能越过后续人工关卡。

## 跨宿主执行

本 reference 是 Codex 桌面端与 Claude Code 的共同合同。原生 Skill 只是可选加速器：

- 若用户在当前宿主显式调用了可用的 `grill-me`、`grilling` 或 `grill-with-docs`，可复用其访谈或领域建模能力，但不得降低本合同的预算、写入边界和停止条件。
- 不得假定模型能自动调用另一个 Skill，也不得要求另一设备具备同名命令、项目脚本或本机 session 状态。
- 原生能力不可用时，由主 Agent 直接执行本文件，不得把能力缺失写成任务失败。

## 输出合同

```yaml
decision_gate:
  mode: skipped | grill-lite | grill-with-docs
  status: pass | blocked | deferred | skipped
  reason: "为什么选择该模式"
  locked_decisions: []
  unresolved_branches: []
  assumptions: []
  requirement_changes: []
  artifacts:
    glossary: null
    adr_candidates: []
    accepted_adrs: []
  questions_used: 0
  questions_limit: 0
```

`deferred` 只能用于用户明确接受且不会阻塞安全执行的非关键分支。任何会改变权限、数据范围、不可逆动作、核心架构或验收结果的未决项都必须是 `blocked`。追问关卡不会替代登录、权限、资金、受监管数据、医学规则、迁移、删除、架构调整、发布或对外发送的人工确认。
