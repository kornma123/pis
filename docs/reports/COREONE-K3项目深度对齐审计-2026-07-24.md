## 一、15 个认知问题的回答

**1. 服务谁？解决哪三个核心经营问题？**
服务独立病理诊断服务商「康湾」的内部 7 角色（PM、财务、主任、技术员、病理医生、仓管、采购），它与约 18 家医院以全流程/代送/代阅片合作 [AUTHORITY_DEFINED，总 PRD v1.6 §1–3]。三问：①库存账实相符吗（库存事实链）；②每例检测"该花多少钱"（BOM 材料标准成本）；③每家医院每月赚不赚钱（院级贡献毛利·内部探索版）[AUTHORITY_DEFINED，PRD §1]。

**2. 当前处于什么状态层级？**
**开发阶段 + 部分代码已合并**：真实解锁院月数 = 0；未部署、未承载真实日常业务、未发布、未生产上线 [AUTHORITY_DEFINED，PRD §1/§7；"合并≠部署≠上线"为既有决定 §10]。当前 GitHub 活动层：两张 Draft PR 待独立复核（见任务地图）[LIVE_VERIFIED]。

**3. 范围内/范围外？**
范围内：进销存事实体系 + 医院端材料标准成本与贡献毛利体系，两套独立体系只经受控事实接口衔接 [AUTHORITY_DEFINED，ABC 退役边界 §1]。范围外（2026-07-24 PM FINAL 新增）：标准工时、人员工资、设备折旧、场地房租、间接费用分摊、ABC activity center/cost pool/cost driver/全成本报表，及把上述费用摊到医院/病例/切片/BOM 的任何产品流程 [AUTHORITY_DEFINED，ABC 退役边界 §1；PRD §8 非目标 10 条]。

**4. 为什么进销存是独立库存事实体系？**
因为只有真实业务单据（入库/出库/退库/报损/退货/盘点/调拨）能改变 `batches.remaining` 及派生库存缓存；BOM、成本计算、核准、版本化都不得触碰库存——两体系若隐式耦合，库存事实就会被"配方推算"污染，账实相符这一问就无法可信回答 [AUTHORITY_DEFINED，ABC 退役边界 §1–2；PRD v1.6 §4.1；CONTEXT.md master 版新增「BOM 与库存边界」术语]。

**5. BOM 可以做什么，绝对不能做什么？**
可以：描述材料配方、做成本测算与推荐依据、版本化与核准链（propose→approve，提交人≠审核人）。绝对不能：预占/扣减/增加/反向修正库存；被解释为实际领用、实际消耗或财务实付；未来即使辅助生成出库草稿，草稿生成本身也不得落库存 [AUTHORITY_DEFINED，ABC 退役边界 §2；PRD v1.6 §4.1「BOM 不反推库存（2026-07-24 PM FINAL）」]。

**6. 贡献毛利扣哪些成本？为什么不能叫真实利润？**
只扣**白名单内可避免材料成本**：一抗（约定真价）、二抗显色（按计费片数）、特染（按盒摊）、组织处理料；排除工时/设备/房租/在编人力/对照片 [AUTHORITY_DEFINED，CONTEXT.md §核心口径]。分子是实收真值、减项是**约定标准成本**——它回答"该花多少"，不做实际成本、不与财务实付逐笔对账，所以永远不能自称利润/真实成本 [AUTHORITY_DEFINED，PRD §2/§8.2]。

**7. 固定成本池的用途？为什么不能分摊？**
它是财务手工认账的**整盘月度汇总数**，只用于组合层覆盖倍数趋势（"整盘扛不扛得住固定开销"），只看趋势不信绝对值 [AUTHORITY_DEFINED，CONTEXT.md §组合体检层；ADR-008]。摊到单院会制造死亡螺旋（顶梁柱被摊亏→砍→固定成本更没人分）；它不是明细费用录入系统，也不得反向恢复工时/设备/工资录入 [AUTHORITY_DEFINED，ABC 退役边界 §1 末段]。

**8. ABC、工时、工资、设备折旧、场地、间接费用现在的状态？**
